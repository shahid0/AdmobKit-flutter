# Smart-media reference

Tool mode: built-in imagegen, new opaque reference board.

## Prompt

Use case: ui-mockup
Create a crisp high-fidelity design reference board for TWO compact AdMob native smart-media templates, not a phone screen. Neutral light gray canvas, two equal-width white cards stacked with clear captions OUTSIDE the ad cards. Caption first "splitMediaLeft"; second "splitMediaRight". Both cards shown at the SAME 360 logical pixel width and compact approximately 136-150 logical pixel height, not feed-card height. No extra template names.
First card: true horizontal layout: left 120x120 square SDK media viewport showing a calm blue-green productivity illustration; 8px gap; right narrow content column. Second card: mirror only the main media/content columns: content left, same square media right. The content identity contains a 40x40 rounded-square app icon beside two text lines: headline "Focus timer", body "Stay focused". Each is single line. BELOW this identity row, metadata across the content column reads a small outlined "Ad" badge, centered dot, "4.5 ★", centered dot, "Free", in one row. BELOW metadata, a full-column dark CTA "Install" with 8px corner radius, minimum 44px height. Tight but readable 4px text gaps, 8px section gaps, 8px outer inset. Main cards corner radius 12px, NOT capsules. Headline 17px semibold, body 14px secondary gray, metadata 12px; no clipping, fake ellipses, extra advertiser name, standalone top attribution row or subtitles.
Top-right corner of each ad keeps a clear tiny SDK AdChoices disclosure region, represented by its conventional small icon; do not invent dismissal or playback controls. All copy and CTA fully contained. The media must stay next to copy, never above it. Ad badge only once per card. No arrows, cross buttons, mock device frames, huge padding, shadows or extra text. Intended as implementation reference, clean practical YouTube-like content hierarchy rather than concept art.
